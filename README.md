# Ride-The-Brig

### Overview:
Ride the Brig is a pirate-themed card game where players will test their luck with a four stage card game. Players win in-game currency to upgrade their odds and unlock cool cosmetics. Make guesses and flip cards to reveal outcomes. Ride the Brig features immersive sound effects, customizable music, save functionality, and upgrade systems that encourage progression.

### Setup:
First you will need to clone the repository, then run the game using "python app.py" in the terminal. The game will run locally, just copy and paste the link that is provided into a browser and play.
